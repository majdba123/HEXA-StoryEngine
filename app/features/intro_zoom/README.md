# Intro Zoom

Intro Zoom is an optional desktop MP4 opening. In the desktop panel, choose **إضافة صورة افتتاحية**, pick a PNG/JPEG/WebP image, click the desired target, adjust magnification while previewing YouTube and Reels, and choose a voice file no longer than three seconds. A job starts without an intro unless the operator explicitly enables it and completes those selections.

The original Final Package, narration alignment, Story, motion, composition, scene timing, and Premiere export stay on their existing paths. The opening is rendered only after each original MP4 passes its normal render and media checks. It begins with the complete image, holds briefly, eases toward the clicked position, then blends into the exact first frame of the existing video. No icon recognition or image reconstruction is used.

The intro is 75 to 90 frames at 30 fps. Short voice recordings are padded with silence. The decoded original audio follows the intro without packet-level AAC concatenation, so AAC priming cannot create a join gap. H.264 video is copied when codec, frame clock, dimensions, profile, and pixel format agree and the decoded join frames match. Otherwise the assembler re-encodes the video and records `video_reencode_fallback` plus its reason in `export.json`; that fallback costs a full-video encode. Every candidate is checked for exact frame count, A/V duration, boundary picture, and decodability before it replaces the incomplete bundle's original output. A failed intro leaves the previously rendered original in a failed, unpublished bundle for diagnosis.

The per-job work directory contains `intro-zoom/request.json`, FFmpeg logs, and per-target `assembly.json`. Original rendered MP4 backups are retained if publication fails. On success, original backups and short intro MP4s follow the existing `keep_intermediates` policy. The published manifest contains the effective configuration and assembly outcome without the uploaded media bytes. Premiere projects do not include the intro; the panel tells the operator this before a Premiere export.
